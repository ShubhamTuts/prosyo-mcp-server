1-minute quickstart

The hosted endpoint is ready. The client config is the URL. There is no API key to create, no developer token to sign up for, and no authentication header to paste. Endpoint: https://app.prosyo.com/ai

The first time Claude or Cursor connects, Prosyo opens an allow screen in the browser so the workspace can be chosen. That confirm is once. It stays out of the config file.

30 tools

Read tools return data immediately. Write tools that contact someone or spend credits prepare the action and finish only after confirm_action once the chat says yes. Pause and save-to-list apply immediately.

Official MCP Registry

Prosyo is published as io.github.ShubhamTuts/prosyo version 1.0.1. The record lives in server.json and points at https://app.prosyo.com/ai over Streamable HTTP, with no API key and no auth headers.

The Model Context Protocol Registry is the community index of public MCP servers. The Model Context Protocol organization on GitHub runs it collaboratively, backed by Anthropic, GitHub, Microsoft, and PulseMCP. The service is modelcontextprotocol/registry. Reference servers live in modelcontextprotocol/servers. Clients and other registries read that upstream metadata.
